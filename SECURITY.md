# Security

If you find a security problem, for example a way for a book file or a downloaded dictionary to harm the app, or for your DeepL key to leak, please report it privately through GitHub's [private vulnerability reporting](https://github.com/ChFlick/Allreads/security/advisories/new) instead of opening a public issue.

Please include what you found, how to reproduce it, and which version (Settings → About shows it). You'll get an answer as soon as possible.

Builds published before v1.0 are signed with a shared debug key. Only install Allreads from this repository's [Releases](https://github.com/ChFlick/Allreads/releases).
